# Codex LAN Remote 0.3.3 Preview

本次同时提供 Android ARM64 APK 与 Windows x64 电脑插件 ZIP。

## 下载与升级

- Android：下载 `codex-lan-0.3.3-preview.apk`，直接覆盖安装同签名旧版，保留原配对、网络配置与缓存。Android 9+、ARM64；仍为开发调试签名预览包。
- 电脑：下载并完整解压 `codex-lan-desktop-0.3.3-preview.zip`，运行根目录 `install-desktop-plugin.ps1`。保留原证书、授权和个人配置，创建桌面及开始菜单“手机连接设置”入口。

## 更新内容

- 手机界面采用回复气泡、可搜索会话列表与独立设置页；工具记录按每轮对话合并折叠，详情按需加载。
- 输入框自动切换发送、追加与停止，右侧增加用户消息定位栏、记录目录与返回最新入口。
- 支持选择电脑实际提供的模型和思考强度，对后续任务生效；底部同步思考、工具执行及等待处理状态。有可见摘要时显示摘要。
- 网络入口移到顶部连接状态，支持局域网直连和 EasyTier 地址切换；电脑设置可增加局域网监听地址。
- 修复电脑新发消息与运行中追加文字在手机遗漏的问题。
- 聊天使用可回收列表，减少长记录滑动时的控件数量；更新时保留阅读位置。

## 验证与说明

37 项 Node 测试、20 项 Android 状态测试及 14 项已安装插件检查通过。已在小米手机验证覆盖升级、聊天同步、停止、工具展开、模型应用和记录定位。模型切换通过当前安装的桌面二进制及实际聊天接口验证。

安装包不含开发者的 EasyTier 参数、网络密钥、连接地址、配对授权、证书或聊天记录。用户需自行配置和配对。安卓包与真机实测文件一致；电脑包由本次源码在 GitHub Actions 中重新构建。哈希仅放在下方版本介绍，不另附校验文件下载。

仍为非官方预览客户端，依赖已验证版本的桌面内部接口；桌面升级后可能需要适配。完整历史分页、附件、新建聊天和局域网自动发现尚未实现。停止任务不保证终止底层项目进程；内置 EasyTier 网卡可能需要 UAC。第三方原生组件的来源和许可证包含在安装包中，完整可复现构建仍待补齐。
