# 手机连接 · Codex 电脑端插件

Windows x64 本地预览版 0.4.13，附带 Node.js 24、EasyTier 2.6.4 core/cli 和 Wintun，无需另装 Node 或 EasyTier GUI。Windows 版 EasyTier 依赖 Packet.dll；发布 ZIP 不二次捆绑此 DLL，安装器会从固定版本的 EasyTier 官方发行包下载并校验后补齐，仅用于本机安装，不安装抓包驱动。首次安装需联网。扫码自动加入 EasyTier 需搭配 Android 0.4.13 或更新版本。

## 安装

电脑插件 0.4.6 起，可在 Codex 的“手机连接”插件页使用“打开手机连接设置”快捷操作，或运行插件提供的设置流程，在当前聊天右侧打开管理页面。也可在技能选择中搜索 `phone-settings`。连接方式、EasyTier、配对与授权均在同一页面管理，无需桌面快捷方式。升级后若当前聊天未出现新入口，请刷新插件或在新聊天中启用插件。

安装完成后，桌面和 Windows 开始菜单会出现 **手机连接设置**。以后直接双击，或在开始菜单搜索此名称，即可修改网络、EasyTier、配对与设备授权；不必先发一条聊天消息。快捷方式不会保存访问令牌，每次打开时自动获取本机凭据。

从旧版升级时运行新版安装器即可。安装器只更新 `codex-lan-local` 的目录来源，保留已有配置、证书和手机授权；如果新来源注册失败，会尝试恢复旧来源。安装包解压目录需保留，供插件目录后续读取。

解压完整发布包，在 PowerShell 运行发布包根目录的 `install-desktop-plugin.ps1`。安装器使用桌面 Codex 内置程序注册本地插件目录并安装“手机连接”，不会修改现有组网服务。插件数据放在 `%LOCALAPPDATA%\CodexLAN`，与可更新的安装缓存分开。

安装后在支持刷新插件的界面刷新，或在新聊天中启用“手机连接”并说“打开手机连接设置”。当前聊天不一定动态获得新工具。也可运行插件目录 `scripts/start-desktop-plugin.ps1` 打开同一设置页面。该页面仅监听本机回环地址，由每次后台启动生成的访问凭据保护；请勿向其他人发送设置页链接。

## 局域网

选择“局域网 / 已有网络”，从完整网卡下拉列表选择电脑 Wi-Fi、以太网、已运行的 ET 或其他虚拟网卡地址，也可手动填写。再填写远控端口，点击保存并启用。此页不显示或提交 ET 参数。局域网、已有 ET、内置 ET 分别保存地址和端口，切换页面保留各自草稿，只有保存并启用才切换运行连接。“仅保存设置”不会切换当前连接。电脑名称、聊天权限和后台自动启用属于通用设置。

旧版“已有网络”默认归为局域网，读取旧配置时不改写文件。现存内置 ET 参数和加密密钥在保存局域网或已有 ET 时保留；旧版额外的局域网监听入口收敛为独立局域网页面，显式保存后仅启用当前选择的地址。

## 使用已运行的 EasyTier

已运行的 ET 归在“局域网 / 已有网络”，从网卡列表选其虚拟 IP。插件不会读取密钥，也不管理外部实例。手机先自行入网，再扫码配对；此二维码不导出网络参数，不强制切换手机的网络方式。

## 内置 EasyTier

选择“内置 EasyTier”，填写组网名称、密钥、静态虚拟 IP/前缀、底层节点 URL 和远控端口。监听地址自动取虚拟 IP，无需另填本机 IPv4。组网 TCP 监听和管理端口直接显示，便于处理与现有实例的端口冲突；停止和管理员入口收在 ET 管理与权限中。已有网卡子网、管理端口和监听端口发生冲突会停止本次启动，不接管或终止现有组网进程。

网络密钥用当前 Windows 用户的 DPAPI 保存，配置页面不回读明文。原生程序通过私有子进程环境获得密钥，不写入命令行；原生日志和完整 RPC 输出不转发到设置页。

首次创建虚拟网卡可能需要管理员权限。如果启动提示权限问题，可从插件目录运行 `scripts/start-desktop-plugin.ps1 -Administrator`，在 Windows UAC 中自行确认。它将正常关闭本插件后台，随后以管理员身份重新启动；过程中手机会断开。已有网络模式通常无需管理员权限。组网参数改变后需停止连接再重新启动，以免混用两个配置。

## 手机配对与授权

服务启动后可生成新的十分钟配对码。Android 首次连接页点“扫码添加电脑”，直接识别电脑二维码，也可从图片识别或粘贴完整配对信息。二维码跟随选择的连接方式，切换或编辑设置会清除旧码。尚未启用时按钮显示“保存启用并生成配对码”，点击后先校验网络参数，再保存、启动和生成，避免漏掉启用步骤。内置 ET 的电脑地址要包含子网前缀（例如 /24，按实际组网调整）；端口被占用或启动失败时不会生成不能使用的码。重新生成配对码不撤销现有设备。

选择“已有网络”默认生成局域网配对码，请填写电脑局域网 IPv4。手机确认后使用局域网直连，不导入组网参数。选择“内置 EasyTier”时，直接生成二维码，手机地址默认由 EasyTier DHCP 自动分配。手机扫码后点击“加入 EasyTier 并配对”，确认导入网络名称、密钥、DHCP 模式和节点，允许系统 VPN 授权后启动组网并验证电脑证书。若手机正在运行另一套内置组网，先在设置中断开，再导入新网络；不接管其他 App 的 VPN。手机取得实际地址后建立 VPN；DHCP 地址变化时会更新虚拟接口。旧版静态地址配对码仍可读取，手动静态地址需要自行避免冲突。

EasyTier 二维码包含网络密钥，只向自己的手机展示，不要分享截图或完整配对信息。十分钟有效期只约束远控配对码，不会让共享网络密钥失效。页面不在普通状态接口或运行记录里返回此密钥，完整配对 JSON 默认折叠，过期、切换方式或隐藏页面时清除展示。

已授权手机显示名称和最近是否有请求，可逐台撤销。撤销后即使处于同一 EasyTier 网络也无法读取聊天或控制任务，需要重新配对。

手机设置 → EasyTier 组网支持添加官方公共节点和打开官方文档。添加节点只修改待保存表单，保留已有节点并去重；点击保存才会写入加密配置。默认节点与来源见 [EasyTier 官方快速组网说明](https://doc.easytier.cn/guide/network/fast-networking.html)，公共服务可用性由上游提供。

## 行为边界

- 本地 MCP 提供打开设置、查看状态、启动及停止四个工具，不将任意桌面 RPC 暴露到手机。
- 后台启动器在首次调用时启动独立的隐藏后台，退出聊天不会立即终止它。可选“后台下次启动时自动连接”；本版不自动注册 Windows 开机任务。
- 设置页关闭不会停止连接。停止连接会断开手机，只停止插件拥有的 EasyTier 实例。
- 桌面内部 IPC 不是稳定公开 SDK；已验证版本范围见项目验证记录，桌面更新后需重新验收。
- 打断聊天不等于停止底层命令；不提供未经验证的项目进程终止功能。
- 内置实例真正创建虚拟网卡和与用户网络互联，应在填写用户自己的参数及完成必要 UAC 后单独验收；已有网络可直接沿用当前手机连接。

第三方组件版本、来源、许可证和摘要在插件 `licenses/`、`dependency-hashes.json` 中。官方插件目录上架与本地安装是不同流程，此预览包仅作本地安装使用。

覆盖安装会读取本机加密配置及已保存的网络名称；发布包不包含这些设置。全新安装的网络名称为空，不取 Windows 用户名或电脑名。扫码二维码包含组网凭据，只向自己的手机展示。
