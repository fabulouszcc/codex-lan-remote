# Codex LAN Remote 0.3.4 Preview

修复大聊天无法进入实时就绪状态，以及手机手动同步时误报连接中断。

## 下载与升级

- Android：下载 `codex-lan-0.3.4-preview.apk`，覆盖安装同签名旧版；Android 9+、ARM64，保留配对、网络配置和本地缓存。
- 电脑：完整解压 `codex-lan-desktop-0.3.4-preview.zip`，运行根目录 `install-desktop-plugin.ps1`。保留原配置、证书及设备授权。

## 修复内容

- 桌面实时适配器支持超过旧 32 MiB 限制的合法聊天快照，仍保留 128 MiB 上限。避免大聊天令共享实时连接断开、其他聊天也一直显示未就绪。
- 增量更新仅复制变更路径，保留旧状态不可变性，避免每次流式更新复制整份大聊天。
- 工具详情总量达到显示上限后停止序列化后续内容，手机返回体仍保持独立的体积限制。
- 手机手动同步、切换聊天或连接地址时，旧轮询的取消不再被当成网络故障，也不会用旧请求结果覆盖新选择。
- 轮询和通知审批使用独立请求客户端，刷新不会取消正在提交的审批。

## 验证

39 项 Node 测试、21 项 Android 状态测试及 14 项已安装插件检查通过。使用已安装桌面 Codex 验证约 50 MB 的真实聊天快照可以读取，手机投影约 1.3 MB；升级后两个现有聊天均恢复实时就绪，局域网与 EasyTier 地址的状态接口均返回成功。

本轮安卓取消请求处理由状态测试覆盖；ADB 当前不可用，尚未在手机复测此版本的同步按钮。需要同时更新电脑插件与手机 APK 才能获得全部修复。

安装包不含开发者的组网密钥、连接配置、证书、设备授权或聊天记录。仍为非官方开发调试签名预览版，依赖桌面内部接口；其余功能与限制见 0.3.3 版本说明。SHA-256 仅放在下方版本介绍中，不提供单独校验文件下载。
