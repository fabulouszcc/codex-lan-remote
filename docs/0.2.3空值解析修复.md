# 0.2.3 Android 活动任务空值解析

0.2.2 的手机代码通过 `optString("activeTurnId", "")` 判断是否存在活动任务。Android JSONObject 将 JSON null 转成字符串 `"null"`，而此前 JVM 测试所用 JSON-java 返回默认空字符串。手机因此在电脑空闲时误发 steer，收到“没有正在执行的任务”。真实回执确认此前多次失败操作为 steer；Android 源码明确记载这一转换行为：

https://android.googlesource.com/platform/libcore/+/refs/heads/main/json/src/main/java/org/json/JSONObject.java

修复：

- 网关空闲或未就绪时统一返回空字符串，已安装 0.2.2 的手机也能恢复正确判断。当前网关已重启应用此修复，配对身份和授权保持。
- 手机读取原始类型，只接受字符串任务 ID，拒绝 JSON null、字面字符串 null 和数字；显式无活动任务时不回退缓存。
- JVM 测试替换成 Android JSON 实现的移植库 `com.vaadin.external.google:android-json:0.0.20131108.vaadin1`，仅用于测试，不打包进 APK。新增回归明确断言 Android 的 null 字符串转换，避免用另一套 JSON 语义误验通过。

验证：Node 23 项通过；使用 Android JSON 实现的 JVM 测试 11 项通过；APK 构建、签名、16 KB 对齐检查通过。真实 HTTPS 专用聊天回归 11 项通过，涵盖空闲安全值、按手机解析选择发送、桌面接收、幂等重试仅一轮、收到最终回复及完成后重新返回发送模式。本机测试客户端发起，未冒充手机点击。未发送任务到当前用户聊天。

手机可先在 0.2.2 点击状态文字重新同步，待当前回复结束后测试发送；建议覆盖安装 0.2.3 获得客户端防护。覆盖安装保留配对和 EasyTier 配置，需重新打开并连接。真实手机点击效果仍待用户确认。
