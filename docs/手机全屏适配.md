# 紧凑窗口的会话列表全宽显示

修复 #3。原抽屉宽度使用 `min(windowWidth - 28dp, 400dp)`，手机竖屏会保留右侧灰色区域。现在小于 600dp 的窗口采用全宽、取消背景变暗，并对系统栏、刘海和键盘应用安全边距；较宽窗口保留原 400dp 抽屉。

PJD110 / Android 16 实机比较：竖屏根布局宽度由 1328px 变为 1440px。检查了明亮/深色主题、大字体（1.3）、键盘展开和横屏。搜索、返回和设置入口仍可见。系统计时浮窗正常保留，测试后恢复字体和旋转设置。截图包含私人会话，因此不上传。

未在实体平板或 Android 9–14 上实测。无记录格式、网络配置或授权迁移。
