# 电脑端插件 0.3.0-preview

本次按用户要求先完成电脑端插件，Android 保持 0.2.4。

## 已实现并运行

- 本地 Codex 插件 `codex-lan-desktop@codex-lan-local`，显示名称“手机连接”，通过桌面内置 Codex 的插件命令安装、启用。使用兼容插件清单、独立 stdio MCP 和本地 marketplace；不修改官方桌面程序。
- 四个工具：打开手机连接设置、查看状态、应用配置并启动、停止连接。当前聊天可能需要刷新插件或从新聊天加载工具；独立 MCP 测试不冒充当前聊天已经动态获得新工具。
- 仅回环监听的设置网页，随机访问凭据、同源/Host 校验、请求体上限及串行配置操作。设置页面已在 Codex 浏览器检查，显示当前连接运行、两个实时就绪聊天、一台最近在线手机。
- 已有网络模式填写本机 IPv4、远控端口及授权范围，不接管外部组网。连接地址由用户在本地填写。
- 内置 EasyTier 模式提供名称、密钥、静态 IPv4/前缀、节点、独立监听和本机管理端口，启动/停止及显式 UAC 入口；不按进程名称批量终止程序。两种模式的地址和端口分别保存。
- 网络密钥使用当前 Windows 用户的 DPAPI；配置和密钥目录仅当前用户与 SYSTEM 可访问，公开设置接口不回传密钥或密文。原生 secret 经子进程环境传递，不出现在命令行，原始配置/RPC/日志不直接展示。
- 配对码无需重启服务即可更新，十分钟有效；配对二维码、复制信息、逐设备撤销、最近连接状态已接入。二维码不包含组网密钥，手机现有配对粘贴方式继续可用。
- 沿用旧证书和手机授权记录迁移到 `%LOCALAPPDATA%\CodexLAN`。旧 Node 网关已在核对具体进程后停止，现由插件后台同时提供本机设置和手机远控服务；原系统 EasyTier 保持运行，插件显示未拥有该实例。

## 构建与依赖

发布包位于 `.local/releases/codex-lan-desktop-0.3.0-preview.zip`，约 49 MB。源程序分别在 `desktop/`、`server/`，源插件清单在 `plugins/codex-lan-desktop/`，`scripts/build-desktop-plugin.ps1` 组装本地 marketplace 与可安装插件。

附带 Node.js 24.14.0、EasyTier 2.6.4-8428a89d、Wintun 0.14.1、QR 生成脚本。EasyTier 原官方 Windows 程序加载时依赖 Packet.dll，不能只打包 core/cli。发布 ZIP 排除此 DLL；安装器从 EasyTier 官方固定发行包下载并校验后为本机补齐，不安装抓包驱动。当前机器已准备此依赖。

固定 EasyTier ZIP SHA-256：`27af91e270e554709b048bd32327fefd2dfce5062ae1e8701af7550c6f525f84`。来源、第三方许可证与单文件摘要随包附带。程序文件与可写数据目录分离，安装器不会覆盖已有身份文件。

Windows 新建证书使用系统 PKI，无需额外 JDK；证书生成后只导出插件自用证书并清理该次临时证书条目。已处理 Windows PowerShell 模块环境与 Node TLS 的兼容问题。

## 验证证据

- Node 29 项通过，新增本机管理认证/同源/重绑定边界、配置校验、子网冲突、受管子进程归属、RPC 脱敏、Unicode DPAPI 往返、配对轮换与撤销测试。
- 已安装包的清单、五个二进制摘要、MCP 初始化与四工具列表、设置入口、页面/二维码资源及密钥隔离检查通过，见 `.local/verification/desktop-plugin.local.json`。
- 全新 Windows 证书可被 Node HTTPS 加载，EasyTier core 版本及静态配置检查通过，未创建新的 TUN 或触碰已有 EasyTier，见 `.local/verification/desktop-native.local.json`。
- 切换后真实 HTTPS 专用聊天回归 11 项通过：提交、幂等重试仅一轮、流式回答、完成回到可发送状态、配对和撤销。测试消息只发到先前授权的专用聊天。
- 插件后台确认保留原手机授权并收到手机请求；本机设置监听 `127.0.0.1:19547`，手机服务绑定原虚拟网卡地址，两端口由同一插件后台持有。
- ZIP 检查包含插件和 marketplace 清单，不包含配置、证书、设备令牌或 Packet.dll。
- 最终 ZIP 解压到独立验证目录后，安装辅助脚本成功从官方包补齐 Packet.dll，解压版 core 可运行并报告 `2.6.4-8428a89d`。最终 ZIP SHA-256：`938325e50342d9f797fb00fca5ea125f75229586e83fdc7b82ac01ce68d7c108`。

## 尚需用户参数的验收及范围

内置模式真正创建 Windows 虚拟网卡、与用户自己的组网节点互联，需要用户填写组网参数并按需确认 UAC；本次保留已工作的外部 EasyTier，没有冒称该场景已实测。未增加自动发现、工具清单同步、Windows 开机任务或未验证的项目进程终止能力。后台当前常驻，关闭页面不停止服务；重启电脑后需启动插件后台或调用插件工具，已保存的自动连接选项才会生效。

官方本地插件打包/安装依据：https://developers.openai.com/plugins/build/plugins 。公开目录上架资格与本地安装不同，本次没有发布到公共目录。
