# Codex LAN Remote 0.4.16 Preview

手机界面、扫码配对和电脑后台体验更新。请同时升级电脑插件与手机 App，以使用全部功能。

## 下载与安装

- **Android**：下载 `codex-lan-0.4.16-preview.apk`，支持 Android 9+、ARM64。同签名旧版可直接覆盖安装，保留配对、网络配置与本地记录。
- **Windows**：下载并完整解压 `codex-lan-desktop-0.4.16-preview.zip`，运行根目录 `install-desktop-plugin.ps1`，保留原连接配置、证书和手机授权。

也可以把仓库 [README 中的安装指令](https://github.com/fabulouszcc/codex-lan-remote#1-安装电脑插件)复制发给电脑上的 Codex，让它完成插件安装。

## 更新内容

- **额度与连接状态**：手机右上角改为双额度圆环，点按查看剩余比例和重置时间；连接圆点以不同颜色区分已连接、处理中、等待与离线等状态。设置入口保留在会话侧栏。
- **手机聊天体验**：优化模型与思考强度选择、工具记录折叠、右侧历史快速定位、输入框及发送／停止操作，增加开屏动画。
- **桌面消息同步**：同步电脑输入的消息，支持在手机查看并回答需要用户回复的问题，以及处理审批。
- **扫码配对**：支持相机、图片和粘贴配对信息；根据连接方式生成二维码。内置 EasyTier 扫码入网默认使用 DHCP 分配手机虚拟地址。
- **网络设置**：分开管理局域网／已有网络与内置 EasyTier，提供统一的组网、配对和设备授权入口。
- **后台自动恢复**：开启后由当前用户 Windows 后台任务保持连接，登录时自动恢复，退出或重启 Codex 不会结束连接后台。

## 开始使用

在电脑打开「手机连接设置」，选择连接方式并保存启用，生成配对二维码；手机点「扫码添加电脑」完成配对。电脑需保持开机，远控聊天时 Codex 桌面端需运行。

首次使用内置 EasyTier 时，按提示确认 Windows 管理员权限和 Android VPN 授权。配对二维码包含连接凭据，请只向自己的手机展示。

这是非官方、开发签名预览版，依赖 Codex 桌面内部接口。
