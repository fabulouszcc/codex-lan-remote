# Codex LAN Remote 0.5.0

新增中文离线语音输入，完善多聊天同步、发送模式和文件预览。请同时升级手机 App 和电脑插件。

<!-- codex-lan-update: {"minDesktopVersion":"0.5.0"} -->

## 下载与安装

- **Android**：下载 `codex-lan-0.5.0.apk`，支持 Android 9+、ARM64。同签名旧版可覆盖安装，保留配对和本地配置。
- **Windows**：完整解压 `codex-lan-desktop-0.5.0.zip`，运行根目录 `install-desktop-plugin.ps1`。升级保留连接配置、证书和手机授权。

也可将 [README 中的安装指令](https://github.com/fabulouszcc/codex-lan-remote#1-安装电脑插件)发送给电脑上的 Codex，帮助完成插件升级。

## 更新内容

- **离线语音输入**：输入框为空时长按按钮说话，文字直接进入草稿，不自动发送。首次使用提示下载约 42 MB 中文模型，支持进度、取消和失败重试，下载后无需联网识别，音频不上传。退出前台停止录音；下载提示适配明亮和深色模式。
- **发送与排队**：输入文字后显示发送箭头，任务进行且输入框为空时显示停止按钮；输入框底部提供「排队／插话」选择，排队消息可查看或移出。成功发送后直接显示消息，失败时提示并保留草稿。
- **会话列表**：优先同步当前聊天，再后台同步其他聊天；按桌面项目分组并折叠展示，同步置顶及顺序，支持在项目内新建聊天。
- **状态与连接恢复**：记忆已验证的局域网地址，连接失败时尝试同一电脑的历史地址；改善聊天结束后仍显示处理中、失效聊天阻碍连接等情况，增加额度、速率和上下文限制的中断提醒。
- **文件与表格**：补充 Markdown、Word 等常用文件预览，改善段落、表格和基础公式展示；聊天及 Markdown 表格支持横向滑动，文件内容仍按点击加载。

## 使用说明

首次使用语音需下载模型并允许麦克风「仅在使用应用时」权限。设置中可查看离线模型状态，识别内容仍需手动确认发送。

文件预览需要电脑在线且原文件仍存在，单个文件最大 32 MB。预览转换无法保证复杂 Office 排版和公式与原应用完全一致，可通过更多菜单保存或使用其他应用打开。

电脑需保持开机，远控聊天时 Codex 桌面端需运行。配对二维码包含连接凭据，请只向自己的手机展示。

这是非官方项目，安装包使用开发签名，依赖 Codex 桌面内部接口。自动更新提醒针对主版本或次版本升级，本次次版本升级支持自动提醒，也可从设置手动检查。
