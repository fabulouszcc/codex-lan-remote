# Codex LAN Remote 0.4.17 Preview

新增手机文件预览、明暗主题和更新检测，改善问题回答与多聊天操作体验。请同时升级手机 App 和电脑插件。

<!-- codex-lan-update: {"minDesktopVersion":"0.4.17-preview"} -->

## 下载与安装

- **Android**：下载 `codex-lan-0.4.17-preview.apk`，支持 Android 9+、ARM64。同签名旧版可覆盖安装，保留配对、网络配置与本地记录。
- **Windows**：下载并完整解压 `codex-lan-desktop-0.4.17-preview.zip`，运行根目录 `install-desktop-plugin.ps1`，保留连接配置、证书和手机授权。

也可以将 [README 中的安装指令](https://github.com/fabulouszcc/codex-lan-remote#1-安装电脑插件)发送给电脑上的 Codex，帮助完成插件升级。

## 更新内容

- **附件与产出文件**：用户图片、文件整合进消息气泡，避免重复显示；任务完成后的产出文件以卡片展示，运行中的文件变更归入工具调用。点击才加载文件内容，优先同步消息。
- **图片与 PDF 预览**：圆角小卡片展示图片，支持缩放；PDF 支持连续上下翻页、双指缩放和拖动。更多菜单支持保存到本地、使用其他应用打开，文本和代码也可预览。
- **显示模式**：新增黑色、明亮模式，可按所选城市的日出日落自动切换；同步调整明亮模式开屏画面与页面配色。
- **自动组网**：保存为内置 EasyTier 连接模式后，再次进入 App 自动恢复组网，首次仍需确认 Android VPN 授权。
- **问题回答与任务状态**：问题卡片内直接输入，改善键盘闪退和输入丢失；清理已结束、取消或回答过的请求，支持在手机暂时隐藏待答卡片。按聊天管理发送状态，减少其他聊天任务导致的只读状态。
- **更新检测**：设置中检查 App 和电脑插件版本，提供统一的圆角界面。主版本或次版本升级时自动提醒，可选择现在更新、下次提醒或忽略该版本；补丁版本支持手动检查。
- **安装权限引导**：首次启动提供安装更新所需权限的引导，可跳过，之后从检测更新页面开启。更新通过 GitHub 下载，安装仍需用户确认。
- **Windows 后台启动**：登录后静默恢复后台服务，避免弹出 PowerShell 窗口，并改善开机网络尚未就绪时的恢复。

## 使用说明

文件预览需要电脑在线且原文件仍存在，单个文件最大 32 MB。未点击的附件不会随聊天记录自动下载。电脑本地界面中的“暂不回复”可能不会同步到手机，可在手机暂时隐藏对应卡片。

电脑需保持开机，远控聊天时 Codex 桌面端需运行。配对二维码包含连接凭据，请只向自己的手机展示。

这是非官方、开发签名预览版，依赖 Codex 桌面内部接口。
