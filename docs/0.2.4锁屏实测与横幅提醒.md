## 调整

- 原任务结果类别为 IMPORTANCE_DEFAULT，不足以申请横幅。新增高重要性的结果类别，默认配置迁移到此类别；已明确关闭或自行调整旧类别重要性时保留用户选择，通过设置入口自行开启。Android 不允许应用直接提升已创建类别的重要性。
- 保留原高重要性审批类别；增加两个专用系统设置入口，提示检查悬浮通知、锁屏通知和勿扰。系统是否弹出横幅仍由用户及 HyperOS 决定；息屏亮屏行为也由系统设置决定。
- 实测确认桌面文件 diff 是完整字符串，旧版误按对象解析，导致短差异也没有“允许一次”。现接受完整且总显示长度不超过 1200 的字符串差异。空值、未知对象、截断或超长内容仍须进入聊天审阅，通知动作继续要求系统解锁并绑定请求与轮次。
- Android JSON 实现下 13 项 JVM 测试通过，包含短字符串差异可快捷允许、未知/截断/超长差异不可快捷允许和 null 命令不可快捷允许。APK 构建成功。通知横幅与手机允许审批仍待安装后复测。

覆盖安装 `.local/releases/codex-lan-0.2.4-preview.apk` 后重新打开 App、连接 EasyTier。进入“通知与后台同步设置”中的“任务完成：横幅/锁屏提醒”“需要审批：横幅/锁屏提醒”，允许悬浮与锁屏通知。应用层也需开启悬浮通知。后台同步和 EasyTier 运行提示可继续关闭。

官方依据：

- Android 通知类别与重要性：https://developer.android.com/develop/ui/compose/notifications/channels
- 小米悬浮通知开关：https://www.mi.com/global/support/article/KA-33184/
