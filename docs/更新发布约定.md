# 应用更新检测

手机设置中的「检测更新」读取本仓库的 GitHub Releases。启动自动提醒仅针对主版本或次版本升级（如 0.4 → 0.5、0.x → 1.0）；补丁版可手动检查。当前安装的是预览版时允许检查已发布的预览 Release，正式版不自动转入预览通道。草稿、只有 Git 标签而未发布 Release、没有对应安装包的版本均不作为可下载安装更新。

「现在更新」使用 Android 系统下载管理器，从 GitHub Release 下载 APK。Android 10 及以上保存到 Downloads；Android 9 使用应用下载目录。用户可在系统下载列表查看进度并打开安装包，安装仍由系统确认，不会静默安装。「下次更新」仅关闭本次启动的提醒，下次启动继续提醒；「忽略更新」只忽略该版本，手动检查仍可看到它。

首次启动会提供安装应用权限引导，可暂时跳过。之后可在「检测更新」中查看权限状态，并进入系统设置开启；是否授予此权限不影响聊天功能。

安卓资产命名 `codex-lan-<版本>.apk`，电脑资产命名 `codex-lan-desktop-<版本>.zip`。Release 标签采用 `v<主>.<次>.<补丁>` 或对应的预览后缀。版本从安装的安卓包和桌面插件 manifest 中读取，不能用聊天同步计数作为版本。

若某个版本需要电脑插件的补丁升级才能兼容，可在 Release 说明中加入：

```html
<!-- codex-lan-update: {"minDesktopVersion":"0.5.0"} -->
```

手机据此提示电脑插件升级；电脑插件安装需在电脑上完成。忽略的手机版本和电脑插件版本分别记录。

更新检查与下载不使用聊天同步连接，也不向 GitHub 发送配对令牌或 EasyTier 配置。自动检查结果缓存 6 小时；手动检查重新请求。公开 API 限流时尝试仓库的发布订阅源和资产列表。检查失败不影响消息收发。
