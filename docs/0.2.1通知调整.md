# 0.2.1 通知调整

- 成功取得电脑实时快照后显示一次“已连接电脑”，4 秒后自动移除；同一次后台同步期间的轮询、切换聊天和断线重连不重复提醒。手动停止后再次连接视为新的同步会话。
- 后台同步通知改为固定的静音运行提示，不再随连接状态反复更新。EasyTier 通知只在状态变化时更新，并设置仅首次提醒、无时间戳、无角标。
- App → 通知与后台同步设置 → 隐藏后台同步运行提示 → 打开此类别，在系统页面关闭该通知类别。若也要隐藏 EasyTier 的应用通知，使用“隐藏 EasyTier 运行提示”入口。
- 保留应用总通知开关、“连接成功（短暂显示）”“需要审批”和“任务完成或失败”类别。关闭后台运行类别不会关闭这些独立类别。
- Android 前台服务必须提交运行通知，App 无法替用户关闭系统通知类别。系统 VPN/活动应用标识仍由 Android/HyperOS 管理；隐藏运行提示不代表停止同步或断开 VPN。

构建版本为 `versionCode=3`、`0.2.1-preview`。沿用本地签名，可覆盖安装；更新后重新打开 App 并连接 EasyTier。桌面网关无改动，也没有重启。

验证：APK 构建成功，现有 Android 状态层 7 项 JUnit 通过。通知实际消失时间、系统设置入口与 HyperOS 后台送达仍需手机实测。
