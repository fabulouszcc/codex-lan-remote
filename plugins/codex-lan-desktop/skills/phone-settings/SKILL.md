# 手机连接设置

调用本插件 MCP 的 `open_phone_settings` 工具取得当前 `settingsUrl`。
使用 `open_in_codex` 的 browser 目标在当前聊天右侧打开该地址；不要求用户去桌面找快捷方式。

设置地址只监听本机回环，URL 片段带有临时访问凭据。直接交给浏览器打开，不在最终回复里回显完整地址、令牌或配对信息。
若当前环境不能打开 Codex 面板，说明限制并提供本机页面入口，不把设置 URL 发送到外部服务。

打开页面后结束本次操作；只有用户另外要求时才保存配置、启动、停止服务或撤销设备。
